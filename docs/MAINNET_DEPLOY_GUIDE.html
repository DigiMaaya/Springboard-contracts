Deploying SpringboardFactory to BSC Mainnet

A walkthrough for running scripts/deployMainnetFactory.js for the first time, written for someone who hasn't deployed a contract before.

!

This deploys to BSC mainnet with real BNB, not a testnet. There is no undo. Read this whole page once before you run anything.

1

Get a private key

A private key is the password that controls a wallet. Whoever has it can move everything in that wallet, forever: so you're about to create one specifically for this deployment, not reuse one you already have.

Create a fresh wallet

  1. Install the MetaMask browser extension if you don't have it.
  2. Click the account icon → Add account → Create a new account. Name it something like Springboard Deployer so you don't confuse it with a personal wallet later.

Export the private key

  1. With that new account selected, click the three dots → Account details.
  2. Click Show private key, enter your MetaMask password, and copy the long string shown.

Never paste this key into a chat window, a document, a screenshot, Slack, or anywhere other than the terminal prompt in step 2. Anyone who sees it can drain the wallet. If it's ever pasted somewhere outside your own terminal, treat it as burned: move funds out and generate a new wallet.

Fund it with BNB

Send a small amount of BNB to this new account's address: just enough to cover gas for one contract deployment. Check the current price at bscscan.com/gastracker; 0.02 BNB is comfortably more than a factory deployment needs under normal gas conditions.

If you're buying BNB for the first time, any major exchange (Binance, Coinbase, etc.) can withdraw BNB directly to a BSC address: just paste this account's address as the withdrawal destination.

2

Run the deployment script

From the project root, with dependencies installed:

$ npm install
$ npx hardhat compile
$ npx hardhat run scripts/deployMainnetFactory.js --network bsc

The script runs over the public BSC RPC by default. If you have your own RPC endpoint (e.g. from a provider like Alchemy or QuickNode) and prefer to use it, add it to .env first:

BSC_MAINNET_RPC_URL=https://your-rpc-endpoint-here

It'll then ask you a few things, one at a time:

PromptWhat to enter
Paste your deployer wallet's private keyThe key from step 1. It's masked as you type: nothing readable appears on screen, and the script never saves it anywhere.
Continue? (yes/no)Shows the wallet address and its BNB balance first. Check the balance looks right, then type yes.
Factory admin addressPress Enter to default to your deployer address, or paste a different address.
